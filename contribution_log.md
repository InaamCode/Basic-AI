# AI-Augmented Workflow - Contribution Log

## Project

Basic AI Agent

## Course

AI-Augmented Workflow

## Objective

The objective of this contribution log is to document how AI-assisted tools
were used during the development of the Basic AI Agent.

---

## Contribution 1: Project Planning

### Task

Plan the initial structure and technology stack for the AI Agent.

### AI Assistance

AI was used to suggest a beginner-friendly technology stack.

### Decision

The project uses:

- Python
- OpenAI API
- Visual Studio Code
- Git
- GitHub

### Student Contribution

The suggested technologies were reviewed and selected based on project
requirements and beginner-level development needs.

---

## Contribution 2: Architecture Decision Record

### Task

Create an Architecture Decision Record for the project.

### AI Assistance

AI was used to help structure the ADR and explain the advantages and
disadvantages of different technology choices.

### Student Contribution

The ADR was reviewed and modified to match the requirements of the
college project.

## Contribution 3: Python Agent Development

### Task

Create a basic Python program that communicates with an LLM API.

### AI Assistance

AI was used to generate an initial implementation and explain the

### Student Contribution

The generated code was reviewed and tested by the student.

part of the program.

## Contribution 5: Documentation

### Task

Create project documentation.

### AI Assistance

### Student Contribution

---

## AI Usage Principles

AI assistance was used as a development and learning aid rather than as
a replacement for understanding the project.

The following principles were followed:

1. AI-generated code was reviewed before use.

2. Generated code was tested locally.

3. Errors were investigated and corrected.

4. Important programming concepts were explained using AI when required.

5. The student maintained responsibility for the final implementation.

---

## Summary

AI-assisted development helped reduce the time required for repetitive
coding and documentation tasks while providing explanations of unfamiliar
concepts.

The project demonstrates an AI-augmented workflow in which the developer
uses AI for assistance while retaining responsibility for understanding,
testing, and validating the final result.
